# 📋 To-Do App with Pomodoro Timer

A simple web app to manage your tasks and stay productive with a built-in Pomodoro timer.

## Features
- Add, check, and delete tasks
- Pomodoro timer (25 mins)
- Light And Dark theme
- Responsive UI using HTML, CSS, and JS

## Getting Started
Open `index.html` in your browser.
